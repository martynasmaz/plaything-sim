# Village systems release — 14 November 2026

This release ships the current game and its supporting source, documentation,
tests, experiment records and visual checks together.

- Added livestock progression, paid enclosures and shelters, winter fodder,
  breeding, dairy, fleece, wool, compost and cattle traction. Knowledge and
  ownership remain separate from persistent physical buildings.
- Added a visual family tree and villager portraits, retaining recorded ancestry
  and deceased relatives across supported saves.
- Centralized the playable scenario settings in `src/scenario.js`, with validation
  and a scenario guide.
- Added raised communal granaries and paid storage-bin expansion. Construction
  requires preservation experience, earlier crafts, materials, a suitable site
  and workdays. Existing racks and food are preserved; rack placement no longer
  stacks baskets and frames over homes.
- Added footbridge handrails and structural bracing. Completed stages reduce
  flood-crossing falls at the ford by 55% and 85%, respectively. Crossing risk
  uses a stable roll per crossing, rather than repeated rolls each animation frame.
- Updated the encyclopedia, notebook and offline build for these systems.
- Corrected river-bank falls: collision and wading follow the drawn tributary
  bend, shoreline destinations and bank routes stay on land, and restored
  villagers start near their own community rather than random map positions.

The release retains existing discoveries, stocks, completed structures and
unfinished projects in supported saves. New techniques still require personal
learning through practice or teaching; drawing and job titles create no buildings.

Verification: 366 automated tests passed; the scenario validator passed; native
Canvas checks cover granary and bridge stages, phone and desktop layouts,
unchanged simulation state while drawing, and offline bundle parsing. An
80-villager restoration fixture produces no opening-frame falls on desktop or
phone. Historical
balance experiments under `reports/` describe their own tested versions and
should not be treated as fresh population forecasts for this combined release.
